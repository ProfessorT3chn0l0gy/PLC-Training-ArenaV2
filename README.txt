PLC ARENA — GITHUB UPLOAD

1. Extract this ZIP (Windows: right-click > Extract All).
2. Open the extracted PLC_Arena_GitHub folder.
3. In your GitHub repository choose Add file > Upload files.
4. Drag index.html, the assets folder, and .nojekyll into the upload area.
   Drag the contents of PLC_Arena_GitHub, not the outer folder or ZIP.
5. Commit changes.
6. To publish a playable page: Settings > Pages > Deploy from a branch > main > / (root) > Save.
   Use the website link shown by GitHub Pages after deployment completes.

Keep index.html and assets together. All training modules and nested simulations are preserved.
If replacing an existing page with another filename, rename index.html to that exact filename before uploading.
The assets folder must stay alongside that HTML file.

You may also open index.html locally after extraction.
